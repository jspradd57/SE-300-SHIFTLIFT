1. Introduction

ShiftLift is a comprehensive web-based application designed to streamline the management of student worker schedules, shifts, and workstations. Built with Spring Boot and Vaadin, it provides an intuitive interface for both administrators and student workers.

Key Features

  • Visual Calendar: Interactive weekly calendar.
  • Automatic Conflict Detection: Prevents double-booking of workers and workstations
  • Seniority System: Automatic seniority calculation based on hire date
  • Max Hours Protection: Prevents students from exceeding weekly hour limits
  • Color-Coded Workstations: Easy visual identification of different workstations
  • PDF Export: Download and print weekly schedules

2. Getting Started

Accessing the Application

Navigate to the application URL (typically www.shiftlift-065i.onrender.com in development) in your web browser.

Login

  1. Enter your username in the first field
  2. Enter your password in the second field
  3. Click "Login" to access the system
Note: Your account type (Administrator or Student Worker) determines which features you can access.

Main Navigation

After logging in, you'll see the Pending Schedule (unpublished) calendar view. Use the hamburger menu (☰) on the left to access different features:

For Administrators:

  • View Published Schedule - View the current published schedule
  • Manage Workers - Add, edit, or delete student workers
  • Manage Workstations - Add, edit, or delete workstations
  • Manage Schedules - Create and publish schedules
  • Create New Shift - Add shifts to the unpublished schedule
  • Download Schedule PDF - Export current schedule as PDF
  • Download Hours Report - Export worker hours report (from unpublished schedule)
  • Change Password - Update your account password

For Student Workers:

  • View Published Schedule - View the current published schedule
  • Request New Shift - Request shifts using unpublished schedule dates (Main Menu only)
  • Download Schedule PDF - Export current schedule as PDF
  • Change Password - Update your account password

Understanding Pending vs. Published Schedules

Pending Schedule (Main Menu)

This is the unpublished schedule where all users create and modify shifts for future weeks.

Published Schedule

This is the official, published schedule visible to all users. Once a schedule is published, it becomes read-only for student workers. Only administrators can edit or create shifts on published schedules.

3. Administrator Features

3.1 Managing Users

Adding a New Worker

  1. Click Manage Workers in the navigation menu
  2. Click Add New Worker button
  3. Fill in the required information:
    • Username: Unique identifier for the worker
    • Email: Worker's email address
    • Password: Initial password (user can change later)
    • Max Hours: Maximum weekly hours (default: 20)
    • Worker Type: Student Worker or Manager
  4. Click Save to create the worker account

Editing a Worker

  1. Navigate to Manage Workers
  2. Find the worker in the list
  3. Click the Edit button next to their name
  4. Modify the desired fields (password, max hours, etc.)
  5. Click Update to save changes
Warning: Deleting a worker will automatically remove all their assigned shifts. Seniority numbers for remaining workers will be recalculated.

3.2 Managing Workstations

Adding a Workstation

  1. Navigate to Manage Workstations
  2. Click Add New Workstation
  3. Enter the workstation name
  4. Click Save

Each workstation is assigned a unique color in the calendar for easy identification.

Deleting a Workstation

Warning: Deleting a workstation will automatically remove all shifts assigned to that workstation.

3.3 Managing Schedules

Creating a New Schedule

  1. Navigate to Manage Schedules
  2. Click Create New Schedule
  3. Select the Start Date
  4. Select the End Date
  5. Click Save
Important: The system allows only 1 published and 1 unpublished schedule at a time. Delete expired schedules before creating new ones.

Publishing a Schedule

  1. Navigate to Manage Schedules
  2. Select the unpublished schedule
  3. Review all shifts to ensure accuracy
  4. Click Publish

Once published, the schedule becomes visible to all student workers uder the View Published Schedule menu option. Only Manager Users will be able to modify the published schedule.

3.4 Managing Shifts

Important: Shifts can be created from both the Pending Schedule (Main Menu) and the Published Schedule views. The date constraints depend on which view you're using:
  • Main Menu (Pending Schedule): Uses unpublished schedule dates - administrators create shifts for the upcoming schedule being prepared
  • Published Schedule View: Uses published schedule dates - only administrators can create or edit shifts on the currently active schedule
Days outside the relevant schedule date range are greyed out and disabled.

Adding Shifts - Method 1: Calendar View

  1. From the Main Menu (uses unpublished schedule dates) or Published Schedule view (uses published schedule dates), locate the day you want to add a shift
  2. Verify the day is within the relevant schedule period (not greyed out)
  3. Click on the day column in the calendar
  4. A dialog will appear with the date pre-selected
  5. Select the Worker from the dropdown
  6. Select the Workstation from the dropdown
  7. Choose Start Time
  8. Choose End Time
  9. Click Add Shift

Adding Shifts - Method 2: Navigation Menu (Main Menu Only)

  1. Click Create New Shift in the navigation menu (available on Main Menu - uses unpublished schedule dates)
  2. Select the shift Date (must be within the unpublished schedule period)
  3. Select the Worker, Workstation, and Times
  4. Click Add Shift

Editing a Shift

  1. Click on a shift block in the calendar
  2. On the Published Schedule view, only administrators can edit shifts (dates constrained to published schedule)
  3. On the Main Menu (Pending Schedule), administrators can edit any shift and student workers can request shifts for themselves (dates constrained to unpublished schedule)
  4. Modify the worker, workstation, or time fields
  5. Click Save to apply changes
Restriction: On the Published Schedule view, non-admin users cannot create or edit any shifts. They can only view the schedule. Student workers can only create shifts from the Main Menu using the unpublished schedule dates.

Deleting a Shift

  1. Click on the shift block in the calendar
  2. Click the Delete button
  3. Confirm the deletion in the dialog box

3.5 Downloading Schedule PDF

The Download Schedule PDF feature allows you to export the latest published schedule as a PDF file for printing, sharing, or archiving.

Exporting the Schedule

  1. Click Download Schedule PDF in the navigation menu
  2. The system will generate a PDF of the latest published schedule
  3. The PDF will automatically download to your default downloads folder
  4. Open the PDF to view or print the schedule
Note: The PDF export includes:
  • Complete weekly calendar view with all shifts
  • Color-coded workstations for easy identification
  • Worker names and assigned times
  • Workstation legend
Tip: Use the PDF export to share schedules with workers who don't have system access or to post printed copies in common areas.

3.6 Downloading Hours Report

The Download Hours Report feature generates a comprehensive report showing total hours scheduled for each worker based on the latest published schedule.

Generating the Hours Report

  1. Click Download Hours Report in the navigation menu
  2. The system will generate a report based on the latest published schedule
  3. The report will automatically download to your default downloads folder
  4. Open the file to review worker hours

Report Contents

The hours report includes the following information:

  • Individual Worker Hours: Total hours scheduled for each worker during the work week (Friday through Thursday)
  • Weekly Breakdown: Hours calculated for each work week within the schedule period
  • Total Hours: Cumulative hours for all workers across the entire schedule

Work Week Definition

The hours report calculates weekly totals based on a work week that runs from Friday through Thursday. This ensures accurate weekly hour tracking even when schedules span multiple calendar weeks.

Tip: Use the hours report to:
  • Verify workers are not exceeding their maximum hours
  • Balance workload distribution across the team
  • Track labor hours for budgeting and payroll purposes
  • Identify scheduling gaps or coverage issues

4. Student Worker Features

Viewing Schedules

Viewing the Pending Schedule

After logging in, you'll see the Pending Schedule (Main Menu). This shows the schedule being prepared for future weeks:

  • Click View Pending Schedule from any view to return to this calendar
  • Use the arrow buttons to navigate between weeks
  • Your assigned shifts appear as colored blocks
  • The color legend at the bottom shows which color represents each workstation
  • Each shift block displays the initials of the assigned worker

Viewing the Published Schedule

To see the official, current schedule:

  • Click View Published Schedule in the navigation menu
  • This shows the finalized schedule that is currently in effect
  • Days outside the schedule period appear greyed out
  • You can view but not edit shifts on this schedule

Requesting Shifts

  1. Navigate to the Pending Schedule (Main Menu)
  2. Click on a day within the unpublished schedule period (non-greyed days)
  3. A dialog will appear - select your desired workstation and time
  4. Click Add Shift to submit your request
Note: Non-admin users can only create shifts for themselves and only from the Main Menu (Pending Schedule view) using the unpublished schedule dates. You cannot create or edit shifts on the Published Schedule view.

Understanding Greyed Out Days

Days that appear greyed out with reduced opacity are outside the current schedule period:

  • You cannot create shifts on these days
  • The tooltip will indicate "This day is outside the schedule period"
  • These typically occur when viewing weeks that extend beyond the schedule dates

Understanding Your Seniority

Your seniority is automatically calculated based on your hire date (account creation):

  • Lower number = Higher seniority
  • Senior workers can override junior workers' shifts (when workstation alternatives exist)
  • You'll be notified when attempting to override another worker's shift

Changing Your Password

  1. Click Change Password in the navigation menu
  2. Enter your current password
  3. Enter your new password
  4. Re-enter your new password to confirm
  5. Click Change Password

Downloading Your Schedule

Student workers can download a PDF copy of the published schedule for personal reference, printing, or offline viewing.

Exporting the Schedule as PDF

  1. Click Download Schedule PDF in the navigation menu
  2. The system will generate a PDF of the latest published schedule
  3. The PDF will automatically download to your default downloads folder
  4. Open the PDF to view, save, or print your schedule
Note: The PDF includes the complete weekly schedule with:
  • All shifts for all workers in the published schedule
  • Color-coded workstations matching the online calendar
  • Worker names and assigned shift times
  • Workstation legend for easy reference
Tip: Download the schedule PDF to:
  • Keep a personal copy of your work schedule
  • Print and post your schedule at home or in your workspace
  • View your schedule offline without logging into the system
  • Share your availability with others

5. Seniority and Override System

How Seniority Works

Aspect Details
Calculation Automatically calculated based on hire date (account creation)
Ranking Lower number = higher seniority (e.g., 1 is most senior)
Updates Recalculated when workers are added or removed
Managers Assigned seniority number 0 (highest)

Senior Worker Override

When a senior worker requests a workstation occupied by a junior worker:

  1. System checks if an alternative workstation is available
  2. If available, a confirmation dialog appears
  3. Dialog explains that the junior worker will be reassigned
  4. Senior worker clicks Override to confirm
  5. Junior worker is automatically moved to the available workstation
  6. Senior worker gets the requested workstation
Limitation: Senior override only works when there's at least one other available workstation. If no alternatives exist, the override is blocked.

Admin Override

Administrators have special override privileges with two scenarios:

Scenario 1: Alternative Workstation Available

Outcome: The conflicting worker is automatically reassigned to the available workstation. Both shifts remain active.

Scenario 2: No Alternative Workstation

Warning: The admin receives a clear warning that the conflicting worker's shift will be DELETED. The admin must explicitly confirm this action.

6. Validation Rules

Shift Creation Rules

Rule Description
✓ Time Validation Start time must be before end time
✓ Operating Hours Shifts must be between 8:00 AM and 5:00 PM
✓ No Double-Booking Worker cannot have overlapping shifts
✓ Max Hours Check Student workers cannot exceed weekly max hours (default: 20)
✓ Workstation Conflict Each workstation can only have one shift at a time (unless overridden)

Schedule Management Rules

Rule Description
✓ Schedule Limit Maximum 1 published schedule at a time
✓ Unpublished Limit Maximum 1 unpublished schedule at a time
✓ Date Range Must start on Monday and end on Friday
✓ Date Order End date must be after start date

User Management Rules

Rule Description
✓ Unique Username Each username must be unique in the system
✓ Unique Email Each email must be unique in the system
✓ Account Creation Determines seniority ranking
✓ Max Hours Must be a positive number

7. Blocking Dates & Availability

7.1 Admin: Blocking a Day

Managers (administrator users) can block specific calendar days so that no shifts can be scheduled on those dates. Blocking a day can be done from the sidebar Block Days section while preparing the unpublished schedule or from the calendar context for the active schedule.

  1. Open the Main Menu or the Published Schedule view.
  2. In the sidebar, find the Block Days section and select a date with the date picker (constrained to the current schedule period).
  3. Click Block. If there are existing shifts on that date, a confirmation dialog will warn you that blocking the date will delete those shifts.
  4. If you confirm, all shifts on that date will be deleted and the day will be blocked. A notification confirms the action.
  5. To reopen the date for scheduling, select the date in the same section and click Unblock.
Warning: Blocking a day that already contains shifts will permanently delete those shifts when you confirm. Use the confirmation dialog carefully.

7.2 Student: Blocking Your Availability

Student workers can block specific dates when they are unavailable to work. These blocked dates prevent the system from assigning or allowing the student to be scheduled on those days.

  1. Open the Main Menu (Pending Schedule view).
  2. Locate the Blocked Dates area in the sidebar which lists your currently blocked dates.
  3. Use the Select Date date picker to choose a date within the unpublished schedule period.
  4. Click Block to add the date to your personal unavailable dates. A success notification will appear.
  5. To allow scheduling again on a previously blocked date, choose the date and click Unblock.
Note: Student blocked dates are personal—blocking a date as a student prevents only your account from being scheduled on that day. Manager-level blocked dates (see Admin section) prevent everyone from being scheduled.

8. Availability Report

The Download Availability Report feature generates a PDF summarizing worker availability for the latest published schedule. It shows how many workers are available per day across the schedule and highlights potential coverage gaps.

What the Report Contains

  • Daily availability counts: Number of available workers for each date in the published schedule.
  • Student blocked dates: Personal unavailable dates contributed by student workers.
  • Manager blocked dates: Dates blocked for everyone (no scheduling allowed).
  • Workforce summary: Quick overview of days with low coverage that may need additional staffing.

How to Download

  1. Open the Published Schedule view (use the navigation menu).
  2. Click Download Availability Report in the left navigation or top actions.
  3. The system generates a PDF from the latest published schedule and starts the download automatically.
Tip: Run the availability report before publishing or finalizing a schedule to identify days that need more staff coverage.

9. Troubleshooting

Common Issues and Solutions

Problem: Cannot Create Schedule

Possible Causes:

  • Already have 1 published + 1 unpublished schedule
  • Selected dates don't start on Monday or end on Friday

Solution: Delete expired schedules or adjust your date selection.

Problem: Worker Double-Booked Error

Cause: The selected worker already has a shift at that time.

Solution: Choose a different time slot or different worker.

Problem: Workstation Occupied

Cause: Another worker is assigned to this workstation at the selected time.

Solutions:

  • Choose a different workstation
  • Choose a different time
  • If you have seniority or admin privileges, use the override feature

Problem: Max Hours Exceeded

Cause: Adding this shift would cause the student worker to exceed their weekly hour limit.

Solutions:

  • Reduce the shift duration
  • Choose another worker
  • Admin: Increase the worker's max hours if appropriate

Problem: Cannot Delete User/Workstation

Cause: Database connection issue or constraint violation.

Solution: The system automatically handles cascade deletion. If errors persist, contact technical support.

Tips for Best Results

Tip: Always review the calendar after making changes to verify shifts were created correctly.
Tip: Use the color legend at the bottom of the calendar to quickly identify which workstation each shift represents.
Tip: Download PDF schedules regularly for backup and distribution to workers without system access.
Tip: Delete old schedules regularly to keep the system clean and prevent hitting schedule limits.
